連線 GitHub（只需設定一次）

貼上 GitHub token 後，這個頁面就能直接存檔。token 只存在這台電腦的這個瀏覽器，不會進 repo，也不會傳給別人。

  • 可以直接用 Apps Script 那個 token（只限 product-ops-bridge、Contents 讀寫）
  • 或到 GitHub 新建一個，權限設定相同

沒有連線 GitHub：改用手動存檔

1. 按「複製並開啟 GitHub」：新的對應表會複製到剪貼簿，同時開啟 GitHub 的編輯頁。
2. 在 GitHub 編輯頁全選、貼上，按右上角「Commit changes」。

或者先連線 GitHub，之後就能一鍵存檔。
